# Pitlane v0.4.3 customer-first Garage — development note

This file describes **development/UI work** in the repository. It is **not** the currently published customer APK.

The current public release is defined by:
- `dist/PUBLIC_RELEASE_VERSION.txt`
- `dist/pitlane-update.json`

At the time of this note, the public release remains **v0.2**.

## Garage changes described here

The Garage opens with a clear customer-use panel before Afiléon Motorsport reference vehicles.

Users can:
- search the built-in vehicle catalogue;
- choose a year/generation where relevant;
- add an unlisted vehicle manually;
- use their own car regardless of whether it is an Afiléon Motorsport vehicle.

Afiléon Motorsport vehicles remain highlighted below the customer controls as reference examples.
