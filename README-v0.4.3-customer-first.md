# Pitlane v0.4.3 customer-first Garage

The Garage now opens with a clear customer-use panel before Afiléon Motorsport reference vehicles.

Users can:
- search the built-in vehicle catalogue;
- choose a year/generation where relevant;
- add an unlisted vehicle manually;
- use their own car regardless of whether it is an Afiléon Motorsport vehicle.

Afiléon Motorsport vehicles remain highlighted below the customer controls as reference examples.
